# Myntra Fashion Analytics Dashboard

## Project Overview

This project focuses on analyzing Myntra fashion product data using Python, Pandas, SQL, and Power BI. The main objective of the project is to extract meaningful business insights from fashion product data and present them through an interactive dashboard.

The project includes:

* Data cleaning and preprocessing using Python
* Exploratory data analysis using Pandas
* Business query analysis
* Interactive dashboard creation in Power BI

---

# Tools & Technologies Used

* Python
* Pandas
* MySQL
* Microsoft Power BI
* CSV Dataset from Kaggle

---

# Project Workflow

## 1. Data Cleaning & Preprocessing

The dataset was cleaned using Python and Pandas by:

* Removing unnecessary columns
* Handling missing values
* Filling null values using mean, mode, and default values
* Removing duplicate records
* Exporting cleaned data for analysis

### Cleaning Steps Performed

* Removed:

  * URL
  * Description

* Missing Value Handling:

  * Discount Price → Filled using mean
  * Discount Offer → Filled using mode
  * Ratings → Filled with 0
  * Reviews → Filled with 0

* Removed duplicate rows

# Business Questions Solved

The project answers multiple business-related questions such as:

* Which brands have the highest number of products?
* Which brands receive the most reviews?
* Which products have the highest and lowest ratings?
* What are the costliest and cheapest products?
* Which categories have the highest average ratings?
* What is the average original price vs discounted price by category?
* Which brands perform best based on customer ratings?

# Key Insights

* Women’s fashion products dominate the inventory dataset.
* Roadster is the most reviewed brand.
* Indian Wear and Western categories contain the highest number of products.
* Average product rating across the platform is above 4.
* Some brands maintain high customer ratings consistently despite lower product counts.
